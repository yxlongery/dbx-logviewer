# proxy_route 只转 TCP，文件型插件借隧道读远端不可行

### Summary
B3 路线（复用 DBX 隧道读远端日志）不可行：`proxy_route` 是多端点协议（Kafka 等）的 SOCKS5 路由，隧道转的是 TCP 端口，`std::fs`/SFTP 读不到远端文件；要借隧道必须自带 SSH 客户端，即回到 B1。

### Details
- 官方文档：`runtime.host/port` 为隧道转换后端点；`proxy_route` 下发 `runtime.proxy`（SOCKS5）供多端点拨号；未声明则静态转发，要求标准 host/port 单一端点。
- 文件路径无法映射成 host:port，故文件型插件与隧道机制正交。

### Suggested Action
远端文件需求直接走 B1（russh + SFTP），不再评估隧道复用。
