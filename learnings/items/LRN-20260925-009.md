# 跨容器日志给 DBX 看的挂载模式

### Summary
sidecar 只能看见 DBX 容器内文件；看其他容器日志不改代码，宿主 `docker-compose.yml` 加一条只读 bind（挂整个日志目录），重启后 UI 直接链容器内路径。

### Details
- 改法：`- /vol1/1000/docker/<服务>/logs:/app/data/<服务>:ro`，与现有 `/orig/*.db:ro` 同类行放一起；DBX 以 root 运行，`root:root 700` 的日志可读，无需改权限。
- 挂目录不挂单文件：按天轮转的新文件自动可见，不用再改 compose。
- 前提：对方日志已落盘文件；只有 stdout 的先让那边落盘（`link` 链不了 stdout）。
- 备份：改前 `cp docker-compose.yml /tmp/dbx-compose.bak-<日期>`，生产 compose 不在 git，备份是唯一后悔药。

### Suggested Action
以后每接一个容器的日志，照抄一行；接多了迁统一日志根（B 方案）。
