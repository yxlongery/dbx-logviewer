# SSH远程日志路线待决策（B1/B2/B3）

- **来源**：2026-09-28 会话，用户选远程B方案后第1步调查结论
- **问题/计划**：`dbx` 容器（Debian 12）内无 `ssh/scp/sftp`，原定 `std::process` 调系统 `ssh`（零新依赖）走不通；Rust SDK 无 Secret Store API，密码只能走 connection 表单透传；官方 schema 支持 `binding: secret/password` + `visible_when` + `fieldPicker` + `proxy_route`（语义待查）
- **可选解**：B1 `russh` 纯Rust（加依赖+async，改动最大）；B2 包内置静态ssh（二进制体积大）；B3 查 `proxy_route`/隧道复用语义；回退 A（远程装DBX）/C（日志同步到本机）
- **验证口径**：用户明确选定路线后，按路线成功标准验证
