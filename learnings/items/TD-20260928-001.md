- **来源**：2026-09-28 会话，用户选远程B方案后第1步调查结论

- **可选解**：B1 `russh` 纯Rust（加依赖+async，改动最大）；B2 包内置静态ssh（二进制体积大）；B3 查 `proxy_route`/隧道复用语义；回退 A（远程装DBX）/C（日志同步到本机）
- **验证口径**：用户明确选定路线后，按路线成功标准验证
- **进展 2026-09-28**：B3 已查（官方文档：`proxy_route` 仅多端点协议 SOCKS5 路由，隧道只转 TCP，`std::fs` 读不到远端，不可行）；用户定 B1（`russh 0.63` + `russh-sftp 3` + `tokio 1`，`ring` 后端；严格指纹+口令+长连接 tail）；后端已实现（connect/test/browse/search/tail/download 全双模式），musl 下 `cargo check/test` 10/10 通过；待 gnu release 构建 + 远端实测
