# 完成 gzip 日志测试包的跨平台验证

- **来源**：gzip 日志读取支持。
- **当前结果**：18 个 Rust 测试通过，包含本地 gzip 和模拟 SFTP。macOS ARM64 测试包的校验值和后端 RPC 验证通过。
- **待验证**：本次开发机连接 NAS 的 SSH 会话被关闭，Linux 测试包未覆盖安装。Windows 的 `--local-bin` 分支目前复用 NAS 编译的 Linux 后端，需要换成 Windows 构建产物。
- **验证口径**：在 NAS 覆盖安装 Linux 测试包并通过 `ping`，在 Windows 安装含 Windows 后端的测试包。两个环境均能浏览、搜索和下载 gzip 日志。
