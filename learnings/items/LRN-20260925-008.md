# python zipfile 重组 dbxp 会丢执行位

### Summary
`ZipFile.writestr` 默认外部属性为 0，解包后二进制权限变 `0o600`，sidecar 起不来。须照抄官方包各条目权限（`bin` 为 `0o705`）再写回。

### Details
- 发现：本地 `dbx-plugin package` 产 musl 结构包，换入 gnu 二进制重打后，对比官方包发现 `bin/linux-x64/*` 执行位从 `0o705` 掉到 `0o600`。
- 修复：重组时读参考包 `getinfo(n).external_attr` 逐项照抄，`checksums.json` 与包外 `artifact.json`（`sha256` + `size`）同步重算。
- 复核口令：`checksums` 自洽 + `file` 看 interpreter + 安装后 `packageSha256` 与本地一致。

### Suggested Action
凡用 `zipfile` 改写 `.dbxp`，权限照抄、校验重算、安装核对，三步缺一不可。
