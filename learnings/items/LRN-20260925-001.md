# Alpine 下 DBX plugin-cli 可选包手动安装

### Summary
`@dbx-app/plugin-cli` 的各平台 native 二进制放在 `optionalDependencies` 里，Alpine（musl）上 npm 因 libc 不匹配静默跳过安装，需手动从 registry 下 tgz 解压到全局 `node_modules`。

### Details
- 现象：`dbx-plugin --help` 报 `The optional package @dbx-app/plugin-cli-linux-x64-gnu was not installed`。
- `npm install -g --include=optional` 无效（npm 按 libc 过滤）。
- 解法：`curl https://registry.npmjs.org/@dbx-app/plugin-cli-linux-x64-gnu/-/plugin-cli-linux-x64-gnu-<版本>.tgz`，解压到 `/usr/local/lib/node_modules/@dbx-app/plugin-cli-linux-x64-gnu/`。gnu 二进制靠容器一期包自带的 `gcompat` 可跑（有一条 `gnu_get_libc_version: symbol not found` 重定位告警，不影响运行）。
- 版本号用 `npm view @dbx-app/plugin-cli-linux-x64-gnu version` 查询，需与主包一致。

### Suggested Action
Alpine 容器首次装 plugin-cli 后直接走手动补包流程；Dockerfile 加包时把该 tgz 一并烘焙比重建后重下省事。
