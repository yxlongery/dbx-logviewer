# 组包改 manifest 版本号必死

### Summary
DBX 加载插件时校验后端二进制内嵌身份版本（`PluginMetadata::new(id, CARGO_PKG_VERSION)` 烘进去的）必须等于包内 `manifest.json` 的 `version`，不一致直接 `initialization failed` 拒绝加载。

### Details
手动组 dev 预览包时把包内 manifest 改成 `0.1.5-dev`，后端仍是 `0.1.5`，报错：`Plugin backend identity 'io.github.yxlonger.logviewer/0.1.5' does not match manifest 'io.github.yxlonger.logviewer/0.1.5-dev'`。dev 后缀方案作废：dev 包版本号与源码一致，覆盖安装。

### Suggested Action
组包只改包内 `executable` 路径形态，不碰 `version`；版本号只随源码 bump 走。
