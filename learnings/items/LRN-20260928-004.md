# 商店候选 PR 固定模板

### Summary
手动组候选 PR 与自动同步器同模板：标题 `feat(store): submit <plugin-id>@<version>`，文件仅 `candidates/<id>.json`（`targets` 用 GitHub Release 直链 + sha256 + size），正文写变更与验证并注明未签名。

### Details
- 自动同步器标题正文固定（见同步脚本），手动沿用可避免格式分歧；已有同版本候选时同步器幂等跳过，理论不重复。
- 同步器约一小时一轮（cron 15 分钟，实际有效约 1 次/小时）。

### Suggested Action
下次发版可等自动 PR；急用手动时按此模板组。
