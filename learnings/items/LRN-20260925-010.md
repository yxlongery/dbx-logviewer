# project-knowledge 技能 RPC 数量描述过时

### Summary
`project-knowledge` skill 写后端是“7 个 RPC”，实际是连接层 3 能力（test/connect/disconnect）＋ 7 个 `logs/*` 接口（含后加的 `link`/`delete`），README 已按实际的 7 个日志接口写。

### Details
- skill 原文：`backend/src/main.rs` “7 个 RPC：connection/test/connect/disconnect、logs/list/search/tail+stop/downloadChunk”（link/delete 功能加上后未同步更新）。
- 实际（`backend/src/main.rs` 实测）：`logs/list`、`logs/search`、`logs/tail`、`logs/stop`、`logs/downloadChunk`、`logs/link`、`logs/delete` 共 7 个日志接口，另有连接层 `test`/`connect`/`disconnect`。
- 本轮 README 的“日志接口”小节按 7 个 `logs/*` 接口列出，已核对源码常量（`MAX_PAGE_SIZE=500`、`MAX_RETURN_LINES=20000`、`TAIL_POLL_MS=500`、tail 初始 200 行、下载分块默认 2000 行）。

### Suggested Action
下次改动 skill 时把该句更新为“连接层 3 能力 ＋ 7 个 logs 接口（含 link/delete）”；写文档引用 RPC 数量时以 `main.rs` 的 `handle` 分发为准，不要抄 skill。
