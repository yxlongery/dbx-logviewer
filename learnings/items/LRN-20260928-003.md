# Secret 补齐键名是 connection_secrets

### Summary
表单 `binding: secret` 的字段存 `connection_secrets[field.key]`，宿主只在后端生命周期请求补齐；sidecar 读密码/密钥/口令必须搜 `connection_secrets`，搜 `secret` 拿不到（报"密码认证需填写 SSH 密码"）。

### Details
- 官方协议：`config` → `external_config[field.key]`，`secret` → `connection_secrets[field.key]`；标准 `password` binding 映射 common password 字段。
- 本插件 `secret_field` 搜索顺序：`connection_secrets` → `secret` → `external_config` → `config` → 顶层。

### Suggested Action
新加 secret 字段时沿用该顺序；联调先看补齐位置再定解析。
