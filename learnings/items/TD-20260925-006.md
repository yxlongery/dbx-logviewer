# DBX 重启后 invoke 直调返回 LEGACY

- **来源**：1+2+3 部署验证 + 日期
- **问题/计划**：DBX 容器重启后，`POST /api/plugins/invoke` 对本插件所有方法（含 ping）返回 `DBX-LEGACY-0001`（legacyBackend 回退）；重启前同一调用正常。已排除文件因素（恢复 0.1.2 原版 bin/ui/checksums 后依旧）。sidecar 二进制在 NAS 本机经 stdio 直跑正常。
- **可选解 / 计划内容**：从工作台打开验证 UI 路径是否正常；查 DBX 是否有插件激活/重载接口；查 DBX 更新日志是否有 invoke 行为变更
- **验证口径**：直调 ping 返回正常 result，或确认 UI 路径正常且直调问题定位
