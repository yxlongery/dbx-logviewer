# DBX 插件上架三坑

### Summary
模板 workflow 引用的复用工作流 ref（`plugin-sdk-v1`）不存在，要改 `@main`；`Cargo.lock` 与 `Cargo.toml` 版本不一致会被 CI `--locked` 打回；候选包重传/删 Release 不影响已构建资产，但 tag 移动需重跑构建。

### Details
1. `dbx-plugin create` 生成的 `plugin-release.yml` 引用 `t8y2/dbx/...@plugin-sdk-v1`，该 ref 404，Actions 直接失败且 jobs 为空。改 `@main` 后 6 平台矩阵才真正跑起来。
2. 改 `Cargo.toml` 版本后必须同步 `Cargo.lock`（本地跑一遍 cargo build 即更新），否则 `--locked` 报错 `cannot update the lock file`。
3. `release-candidates.json` 下载要走 API 资产接口 + `-L` 跟 302（直链会被代理吞成 0 字节）。
4. 商店 PR 只含 `publishers/<id>.json`（首次）+ `candidates/<plugin-id>.json`；本地 `node scripts/validate.mjs` 报 `awaiting signing` 是预期红，不是错误。

### Suggested Action
发版前清单：workflow ref 有效 → lock 已同步 → Release 发完等构建绿 → 再组 candidates PR。
