# playwright容器互访走代理，DOM验证缺口

- **来源**：2026-09-28 会话，UI折叠改动验证时发现
- **问题/计划**：`playwright-mcp` 容器 `NO_PROXY` 缺容器名（Chromium 不认 `172.16.0.0/12` CIDR），浏览器访问 `http://opencode:5190` 被送代理而失败；本轮 UI 改动（双卡片折叠+摘要+视口高度）仅做了 `div` 平衡 + `node --check` + `git diff` 审查，未做真机 DOM 验证
- **可选解**：宿主 `playwright-mcp` 的 env_file 加 `NO_PROXY` 含 `opencode` 后重启容器，再补 DOM 验证；或记为全局环境缺口修全局 `ENVIRONMENT.md`
- **验证口径**：浏览器打开页面，折叠默认收起、点击展开、摘要更新、无连接按钮禁用均符合预期
