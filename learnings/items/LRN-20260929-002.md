# 纯前端测试包复用旧底包manifest致版本回退

### Summary
`make-test-pkg.sh` 无 `--local-bin` 时不替换 `manifest.json`，底包过旧（本轮底包 `0.1.6`）会导致测试包版本号回退，DBX 落盘多版本并存、激活错乱。

### Details
- 本轮纯前端包 `manifest.version` 为底包的 `0.1.6`，装上后 `versions/` 下 `0.1.6` 与 `0.2.1` 并存；浏览器还可能读到旧版 `ui`（宿主 asset 缓存），现象扑朔迷离。
- 解法：后端/manifest 有变一律 `--local-bin`（用工作区 manifest + 重编二进制）；纯前端改动也建议核对包内 `manifest.version` 再装。
- 附带：`repack-test.sh` 按名只断首个同名连接；多同名/多连接时逐 id 全断（`connection/list` 取 id 循环 `disconnect`）。
- 浏览器侧旧 `ui` 缓存：关工作台重进 + 硬刷新；`about:srcdoc` 套娃内 reload 会丢连接上下文，要 deselect 后重进。

### Suggested Action
打测试包后先 `unzip -p <包> manifest.json` 核对版本，再装；安装被拦看完整 `detail` 点名哪个连接。
