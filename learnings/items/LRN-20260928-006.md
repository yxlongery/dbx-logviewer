# 反代插件包上传放行 20m

### Summary
SSH 版包约 2MB 经反代报 413（默认 1m）；宿主 `dbx.conf` 加 `client_max_body_size 20m` 并 `reload` 后 UI 直传与本机脚本双通道可用。

### Suggested Action
包体积再涨仍够用；超 20m 再调。
