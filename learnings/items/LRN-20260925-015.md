# 单文件页 playwright 验证：容器 IP + 重派 DOMContentLoaded

### Summary
`playwright-local` 禁 `file://`、跨容器 `127.0.0.1` 不通：`python3 -m http.server --bind 0.0.0.0` 起服务后用容器 IP（如 `http://172.19.0.11:5199/`）访问；宿主缺失场景用 `window.dbxPlugin = mock` 后 `window.dispatchEvent(new Event("DOMContentLoaded"))` 重放（监听器挂在 `window` 上，`document` 派发收不到）。

### Details
- 本轮用该法验完目录浏览：根渲染、子目录下钻、面包屑回退、文件名过滤、隐藏/恢复全部，控制台零 error。
- 服务用完按 PID 精确 `kill`，勿 `pkill -f`（命令行自匹配会杀掉自己 shell）。

### Suggested Action
前端单文件改动沿用此套路：语法 `node --check`（先从 html 提 script）+ sidecar DOM 交互断言。
