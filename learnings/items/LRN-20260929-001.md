# 覆盖安装被非默认连接名的活跃连接拦截

### Summary
`scripts/repack-test.sh` 默认只断开 `Log Viewer connection`，其他同插件连接（如 `日志-autofeedemby`）活跃时会报 `Plugin update blocked by active connections` 导致安装失败。

### Details
- 本轮两次踩到：`make-test-pkg.sh linux --local-bin` 末尾调 `repack-test.sh`，`install` 返回 `DBX-LEGACY-0001 ... Plugin update blocked by active connections: 日志-autofeedemby`。
- 解法：带第二个参数显式断开占用连接再装：`repack-test.sh <包> "日志-autofeedemby"`。
- 安装是否成功以后缀为准：落盘 `versions/<ver>/` 时间戳更新 + `ping` 回 `ok:true`，不要只看脚本退出码（`head -c 200` 截断会吞掉 detail）。

### Suggested Action
覆盖安装失败先看完整 `install` 响应的 `detail` 字段，点名哪个连接就断开哪个；常驻多连接时逐个断开再装。
